# Octopad

Connects your AI to Octopad and loads its skills and Octoplan, under the methodology the Octopad server supplies.

The plugin adds the hosted Octopad MCP server (`https://mcp.octopad.app/mcp`). Your client opens the Octopad sign-in the first time the connection is used; nothing runs locally and no API key is needed. Then start a new conversation and ask to use Octopad.

Install steps for Claude, Codex and Cursor, and how the skills are maintained, are in the [repository README](https://github.com/sudolab-co/octopad-plugin#readme).
