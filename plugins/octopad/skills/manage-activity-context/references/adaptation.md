# Adapt from first principles

Start with the decision the AI must support, not a list of documents it could create.

| Dimension | Useful distinction | Documentation consequence |
|---|---|---|
| Actor and responsibility | Who acts, decides or is accountable, as the sources already show. An individual is not automatically a company. | Attribute context; link authoritative platform or governance records, do not duplicate personnel data. |
| Purpose and beneficiaries | Learning, service, public benefit, commerce or another purpose; beneficiary, user, buyer and funder can differ. | Explain the actual purpose; avoid forcing customer vocabulary. |
| Contribution to value | Delivered offering, means of production, coordination tool, experiment, shared infrastructure; several can coexist. | Describe each relevant use separately; a tool's functional documentation does not depend on sales. |
| Economics | Sales, donations, grants, internal budget, unpaid effort, unknown. | Capture a safe relevant summary, not a compulsory business model or financial artifact. |
| Relationships and audience | A project may involve an agency, a client and an operating team. | Place each fact with its owner and authorized audience. |
| Evidence and commitment | Idea, intended direction, observed use, actual sale, explicit decision. | Keep them distinct, attributed and revisable; do not derive one from another. |

- Use these dimensions as optional lenses, not tags to populate or mutually exclusive personas.
- Add an unanticipated dimension only when it changes a real decision.
- For a new case, reconstruct purpose, contribution, ownership, audience and evidence instead of expanding a persona catalog.

## Decide where context belongs

- Before extracting context to another page, identify which section becomes authoritative, preserve its provenance and obtain any required move or overwrite authorization. Leave a link in its place, never a second copy.
- A brief may contain purpose, relevant participants and relationships, contribution to value, chosen direction and non-choices, constraints and source links: possible content, not mandatory headings.
- A diagnosis helps when an actual obstacle drives a choice; do not require "the single obstacle" for every activity.
- A good choice explains what it changes and excludes; generic aspirational strategy is insufficient.
